# Tipo 2 — banco de palavras com uso único

Formato: completar várias frases escolhendo opções de um mesmo banco, usando cada opção apenas uma vez.

## Estratégia

1. Leia primeiro todas as opções e todas as frases.
2. Resolva as combinações mais óbvlias (collocations) primeiro.
3. Marque mentalmente ou risque cada opção já usada.
4. Use pistas gramaticais para as frases ainda ambíguas.
5. Deixe pares parecidos para o final e faça uma conferência global.

## Collocations-âncora

- check my messages
- take a nap
- revise for a test
- feed the cat
- hit the snooze button
- run errands
- stay up late

## Diferença para o Tipo 1

No Tipo 1, cada questão pode ser resolvida isoladamente. No Tipo 2, uma resposta altera o conjunto de opções disponíveis para todas as demais questões. Por isso, o melhor método é resolver primeiro as respostas de alta certeza e usar eliminação nas restantes.
