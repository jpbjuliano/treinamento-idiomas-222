Estratégia de prova

Não tente entender tudo. Procure o que decide a resposta.

Cada habilidade exige uma rotina diferente. A melhor preparação é repetir essa rotina até ela se tornar automática.

🎧

CA — Compreensão Auditiva

Use as duas reproduções com funções diferentes.

  • 1ª reprodução: entenda a situação, quem fala, o problema e a ideia principal.
  • 2ª reprodução: confirme o detalhe que separa a alternativa correta dos distratores.
  • Em ligações telefônicas, procure motivo da ligação, mudança de plano, horário, data e ação final.
  • Se perder uma palavra, continue ouvindo. Não abandone o restante do áudio.
Sinais de mudança: but • however • instead • actually • unfortunately • so • because • although
📖

CL — Compreensão Leitora

Comece pela pergunta e use o texto para provar a resposta.

  • Leia primeiro a pergunta.
  • Identifique palavras-chave e possíveis sinônimos.
  • Localize no texto a frase que sustenta a resposta.
  • Evite escolher uma alternativa apenas porque ela repete palavras do texto.
  • Em ideia principal, considere o texto como um todo antes de responder.
✍️

EE — Expressão Escrita

Clareza, organização e atendimento ao enunciado valem mais do que escrever de forma excessivamente sofisticada.

  • Transforme cada item do enunciado em uma obrigação a cumprir.
  • Planeje rapidamente: introdução, desenvolvimento e conclusão.
  • Prefira frases corretas e claras a estruturas arriscadas.
  • Revise tempos verbais, plural, artigos, preposições e ortografia.
  • Confirme se todos os pontos pedidos foram respondidos.
Gestão de tempo: 10–15% planejar • 70–75% escrever • 15% revisar

Protocolo mental

Uma sequência simples para cada habilidade

CAsituação → problema → mudança → resultado
CLpergunta → palavra-chave → evidência → resposta
EErequisitos → estrutura → escrita → revisão

Como usar a plataforma

Treinar para aprender. Simular para testar.

Modo Treino

Use para aprender com o erro. Responda, veja a correção, abra a transcrição somente depois da tentativa e identifique qual pista deveria ter conduzido à resposta correta.

Modo Simulado

Use para medir desempenho. As questões são randomizadas, as alternativas mudam de posição e a correção fica oculta até a finalização.

Regra prática: uma questão difícil não significa que a prova está perdida. Resolva o que for possível, escolha a melhor alternativa e siga. Não avalie seu desempenho durante a prova.
